API Key 只保存在本机 chrome.storage.local；不会发送给内容脚本。字幕由 OpenSubtitles 提供，下载次数受其账号/API 限额约束。

如何生效

保存后，已打开页面中的字幕面板会通过 chrome.storage.onChanged 自动更新外观；位置会直接更新当前 cue，不必重建轨道。

数据与隐私

扩展不发送字幕、视频、音频或设置。启用 OpenSubtitles 时只发送片名/年份/语言/集数。字幕库缓存在扩展自己的 IndexedDB；清除本地数据会删除设置、缓存和 API Key。

快捷键

Alt + Shift + S 打开或收起面板。可在 chrome://extensions/shortcuts 修改。

字幕匹配与缓存

本地候选和字幕库始终可用；OpenSubtitles 在线搜索需要 API Key 并显式启用。
