## 3. 浏览器烟测

headless Chrome 155 + CDP：

1. 加载测试 SRT，末条结束 122s。
2. 设置视频元数据时长 124s。
3. 点「分析时间轴」。
4. 断言：
   - 建议 `+2000 ms`；
   - 置信度“中”；
   - 警告“字幕条数较少”；
   - 建议文本可见，应用按钮可见。
5. 点「应用建议」。
6. 断言当前偏移为 `+2000 ms`，面板显示 `+2000 ms`。

## 4. 风险与限制

- 只使用尾锚定；片尾/彩蛋、缺失结尾字幕会误判。
- 不是音频/语音识别，不能解决“字幕整体提前/滞后但结尾恰好对齐”的情况。
- 最高只给“中”置信度，且必须手动确认，不会自动改偏移。
- 视频时长未知时不可用。
- 真实扩展安装后的 `<video>.duration`、多视频切换、缓存/在线字幕未单独验收。
- 没有分段对齐、局部漂移修正。
