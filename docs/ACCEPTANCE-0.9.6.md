# v0.9.6 多窗口鲁棒校准验收报告

- 日期：2026-10-18
- 版本：`0.9.6`
- 范围：多窗口音频证据、活动筛选、鲁棒聚合、目标偏移语义
- 结论：**算法与 UI 单测通过；真实站点音频 E2E 仍未完成，不发布 1.0.0**

## 1. 本次实现

### 多窗口

- 标签页音频一次采样约 40 秒。
- 拆成 5 个 8 秒窗口；每个窗口独立估计候选偏移。
- 窗口不足 3 个有效结果时拒绝自动建议。

### 活动筛选

- `alignment/audio-features.js`：
  - 噪声底/峰值估计；
  - 滞回活动阈值；
  - 活动比例；
  - 时间戳单调性与最大间隔检查。
- 活动比例过低的窗口不参与聚合。

### 鲁棒聚合

- `alignment/audio-session.js`：
  - 加权中位数；
  - MAD（中位绝对偏差）；
  - 窗口跨度；
  - 分簇/不稳定拒绝；
  - 高/中/低置信度。
- 结果统一为目标总偏移（不是增量）。

### 时间映射

- 采样期间暂停、拖动、倍速变化，App 会丢弃本次 40 秒会话。
- 每帧保留媒体时间，窗口不能跨时间跳变拼接。

### UI

- 「标签页多窗口 40s」。
- 建议显示：
  - 目标偏移；
  - 高/中/低置信度；
  - 有效窗口数 / 总窗口数；
  - MAD。
- 必须手动确认；低置信度不自动应用。

3. 低证据正确拒绝率达标，错误自动建议率接近 0。
4. 暂停/seek/倍速/DRM 失败路径实测。
5. 全屏、多视频、站点矩阵通过。
