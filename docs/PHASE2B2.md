# v0.4.0：本地候选匹配 UI 报告

- 日期：2026-10-18
- 版本：`0.4.0`
- 范围：本地候选字幕、手动片名/年份/语言、匹配列表、直接加载候选
- 环境：Windows 11 专业版 10.0.26300；Node.js 24.21.0；Chrome 155.0.8059.80

## 1. 本次实现

### 面板「字幕匹配」区

- 可折叠，默认不展开。
- 片名、年份、语言字段：
  - 从页面元数据自动预填；
  - 可手动修正；
  - 「用识别结果」恢复自动识别值。
- 「选择候选字幕…」支持一次选择多个本地 SRT/VTT。
- 「重新匹配」按当前字段重新评分。
- 候选列表显示：
  - 片名；
  - 分数；
  - 置信度（高/中/低）；
  - 文件名、格式、cue 数、年份；
  - 匹配理由（前两条）；
  - 冲突项（前两条）；
  - 「使用此字幕」按钮。
- 选择候选后直接复用已解析的文档，不重新读取文件。

### 本地候选读取

- 最多 16 个文件；单个文件上限 8 MB。
- 复用 `FileDecoder`、`parseSubtitleFile`，与本地加载同一套校验。
- 从文件名解析片名、年份、语言（chs/cht/eng/jpn/kor/中字/双语等）。
- 单个文件失败不会中断其他候选。
- 候选完全在本地处理，不发送片名或文件。
- 没有在线来源时明确提示，不显示假的搜索按钮或结果。

### 评分

沿用 `candidate-ranker.js`：

- 片名 0.50；
- 年份 0.18；
- 时长 0.20；
- 语言 0.07；
- 集数 0.05。

本地候选通常没有可靠视频时长，因此会显示“缺少时长，置信度受限”，
覆盖率不足时不会标成高置信度。

1. 演示页 JSON-LD 自动预填片名 `本地字幕助手演示`、2026、zh。

   - `本地字幕助手演示.2026.chs.srt`
   - `Other.Movie.2020.eng.vtt`
3. 候选列表生成 2 项，第一项分数 100（中等置信度，因缺少时长）。
4. 点击「使用此字幕」，轨道显示、文件信息更新，选中卡片高亮。
5. 手动改为 `Other Movie` / 2020 / en，排序反转，第一项 100。
