# v0.9.0 音频自动校准验收报告

- 日期：2026-10-18
- 版本：`0.9.0`
- 范围：音频可分析性检测 + 实验性音频/字幕相关性校准
- 结论：**数学与 UI 通过；真实站点音频捕获未验证；不宣称生产级自动对齐**

## 1. 本次实现

### 音频可分析性

- `content/audio-calibrator.js`
  - 使用 `video.captureStream()`，不接管/不静音原音频；
  - 报告无音轨、跨域/DRM、静音、AudioContext 不可用等错误。

### 实验音频校准

- 播放 8 秒，100ms 间隔采样 RMS。
- `alignment/audio-aligner.js`：
  - 音频能量归一化；
  - 与 cue 活动做 Pearson 相关；
  - 搜索 ±15 秒，250ms 步进；
  - 静音、样本不足、相关性不足直接拒绝；
  - 最高只给中置信度，必须手动确认。

### 面板

- 「自动分析」区新增：
  - 检测音频；
  - 音频校准 8s；
  - 音频状态。
- 失败时回退手动偏移。

## 4. 未验证 / 限制

- 真实视频站点通常是跨域媒体，`captureStream()` 可能没有音频轨；
- DRM/EME 播放器不可分析；
- 音乐、音效、掌声会降低相关性；
- 8 秒采样可能不足以覆盖对白；
- 未在真实扩展安装版做音频捕获验收；
- 不是生产级自动同步，只是实验性建议。
