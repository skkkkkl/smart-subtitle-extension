# v0.7.1 自动分析安全修复验收报告

- 日期：2026-10-18
- 版本：`0.7.1`
- 触发问题：用户视频 1:28:42，字幕末条 1:21:17，
  自动建议 +444822ms（7分24秒）且可点“应用建议”，导致字幕严重错位。

## 1. 根因

v0.7.0 的尾锚定算法在“视频结尾比字幕结尾长很多”时仍给出建议：

```text
offset = videoDuration - lastCueEnd
       = 5322s - 4877s
       = +445s
```

这通常意味着字幕缺少片尾/彩蛋，而不是字幕整体延迟 7 分钟。
旧 UI 对低置信度建议仍显示“应用建议”，用户一键应用后字幕被推偏。

## 2. 修复

- 尾差超过 **120 秒**：返回 `TAIL_TOO_FAR`，不生成可应用建议。
  - 提示“可能缺少片尾或包含彩蛋；请归零后手动校准”。
  - 不显示“应用建议”按钮。
- 自动建议偏移超过 **120 秒**：返回 `OFFSET_TOO_LARGE`。
- 保留原有：
  - 首条越界限制；
  - 最高中置信度；
  - 手动确认；
  - 不访问音频。

## 3. 回归测试

```text
tests 104
pass 104
fail 0
duration_ms 569.3209
```

新增用例：视频 5322s、字幕末条约 4883s，断言：
- `ok === false`；
- `code === 'TAIL_TOO_FAR'`；
- 提示包含“手动校准”。

## 4. 用户恢复步骤

当前已被应用 +444822ms 时：

1. 点「时间偏移」→「归零」。
2. 确认字幕回到 0ms。
3. 若仍然对不上，用 `−500 / +500` 或数值输入手动校准。
4. 不要再次应用超过 2 分钟的自动建议。

## 5. 验收结论

- 安全修复通过。
- 自动分析仍是启发式；尾差很小的文件才建议自动应用。
- 真实音频/语音对齐、分段对齐仍未实现。
