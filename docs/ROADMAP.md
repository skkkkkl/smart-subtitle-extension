## 3. 1.0 完整版判定

“完整版”指 **桌面 Chrome 1.0** 的功能与质量门槛，不是无限功能。

1. **字幕格式**
   - SRT/VTT 稳定；
   - ASS/SSA 至少一个经验证、许可清晰的渲染方案；
   - 明确记录不支持的特效/标签。

2. **字幕获取**
   - 本地候选匹配和字幕库完整；
   - 至少一个明确配置、审核过条款的在线字幕来源；
   - 未配置来源时显示空状态，不伪造结果；
   - 下载后在本地解析、校准、应用，并写入字幕库。

3. **时间轴**
   - 手动整体偏移；
   - 自动整体偏移估计 + 置信度 + 回退；
   - 分段对齐接口；
   - 低置信度不自动破坏原字幕；
   - 结果按影片标识 + 字幕指纹 + 版本隔离保存。

4. **视频兼容**
   - 多视频、SPA、动态创建/销毁；
   - 容器全屏；
   - 明确的 iframe/DRM/Shadow DOM/Canvas 限制说明；
   - 真实站点测试矩阵。

5. **数据**
   - 设置、缓存、校准记录可保存/恢复/清除；
   - 权限最小化；
   - 隐私说明和网络元数据披露完整；
   - 字幕缓存不写入宿主网页 origin。

6. **工程**
   - 单元测试、浏览器烟测、手动验收清单；
   - 无未说明的“未验证”核心功能；
   - 安装包、版本号和变更记录。

## 4. 当前未达成的 1.0 门槛

- OpenSubtitles 搜索：真实 API Key 的 API 层验证通过，扩展 SW/权限链路待验收；
- 真实扩展源 IndexedDB 持久化：未自动验证；
- ASS/SSA：常用子集已实现，完整 libass 特效/字体/绘制未覆盖；
- 自动偏移：首尾双锚点启发式；音频校准为实验功能，未在真实站点验收；
- 真实站点矩阵：未完成；
- 真实 Chrome 扩展 E2E：未自动验证。

## 5. 外部依赖/阻塞

- OpenSubtitles 已选为公开来源；需要用户自己的 API Key 和域名权限。
  没有 Key 时不会伪造来源或搜索结果。
- ASS 渲染需要先完成 libass WASM 或备选方案的许可、维护、CSP、离线评估。
- 自动校准需要先验证目标播放器的本地音频可读性和模型资源。

## 6. 节奏

- 不承诺具体日期。
- 每个版本是否完成，以测试报告、验收清单和已知限制为准。
- 下一阶段：1.0.0（真实站点音频 E2E 与发布）。
