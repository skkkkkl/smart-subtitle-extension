# 本地字幕助手 · 最终交付版说明

- 版本：`0.9.11`
- 平台：Windows Chrome（Manifest V3）
- 范围：本地/在线 SRT、VTT、ASS/SSA 字幕 + 外观 + 缓存 + 偏移分析 + 标签页音频实验
- 不包含：跨任意站点的完美自动对齐、分段对齐、完整 libass 特效、Android

## 1. 安装

1. 解压 `smart-subtitle-extension-v0.9.11.zip`。
2. 打开 `chrome://extensions/`，开启开发者模式。
3. 「加载已解压的扩展程序」，选择 `manifest.json` 所在目录。
4. 建议固定扩展图标。
5. 打开网页并播放 HTML5 `<video>`，点击图标。

首次点击才通过 `activeTab` 获得当前页权限；刷新网页后需要重新点击。
快捷键：`Alt + Shift + S`。

## 2. 打开设置页

四种方式：

1. 面板右上角齿轮 `⚙`；
2. 面板「字幕外观」→ 底部「更多设置」；
3. `chrome://extensions/` → 本地字幕助手 → 详细信息 → **扩展程序选项**；
4. 右键工具栏扩展图标 →「选项」。

如果面板没有齿轮，先重新加载扩展并刷新网页。

## 3. 加载字幕

1. 选择目标视频。
2. 点击「选择 SRT / VTT / ASS 字幕」。
3. 支持 UTF-8、UTF-16LE/BE、GB18030 回退。
4. 加载后显示文件名、格式、条数、结尾时间。
5. 可「重新加载」或「移除字幕」。

限制：单个文件 8 MB。ASS/SSA 使用专用覆盖层，不走原生 `<track>`。

## 4. 时间偏移

- 快捷按钮：`−500 / −100 / −50 / +50 / +100 / +500 ms`。
- 数字输入后点「应用」。
- 正数延迟，负数提前。
- 「撤销」回退上一次偏移。
- 「归零」恢复原始时间轴。
- 范围：`−3,600,000` 到 `+3,600,000 ms`。
- 偏移后完全落在 0 前的 cue 会被移除，并提示数量。

## 4.1 自动偏移分析

- 「时间偏移」→「分析时间轴」。
- 同时检查首条字幕和末条字幕的偏移方向是否一致。
- 显示置信度、警告；最高为中置信度。
- 点「应用建议」才修改偏移；可撤销。
- 尾差超过 10 秒或首尾锚点冲突时直接拒绝自动建议。
- 没有音频/语音识别；片尾、彩蛋、缺结尾仍可能影响小尾差。
- 视频时长未知时不可用。

## 4.2 多窗口音频校准（实验）

- 标签页音频采样约 40 秒，拆成 5 个 8 秒窗口。
- 每个窗口独立估计，活动不足/时间跳变窗口剔除。
- 加权中位数 + MAD 聚合；有效窗口 <3、MAD 过大或分簇时拒绝。
- 结果为目标总偏移；UI 显示有效窗口数、MAD、置信度。
- 校准诊断面板显示逐窗口媒体时间、音频采样起止、偏移、分数、第二独立峰、峰分差、活动比例和拒绝原因。
- 额外显示跨窗口候选共识：offset/support/medianScore。
- 额外显示整段 40 秒 global 偏移/分数/第二独立峰。
- 峰值 margin <0.03 或贴近 ±15s 边界的窗口不进入聚合。
- 同时显示标准 MAD 与目标残差 MAD。
- 仍需手动确认；真实站点 E2E 未完成。

## 4.3 标签页音频校准（实验）

- 「标签页音频 8s」会请求 `tabCapture` + `offscreen`。
- 捕获当前标签页音频，仅本地采样/分析；不会上传。
- DRM/静音/无音轨标签页可能失败。
- 结果必须手动确认；不保证所有站点可用。
- 真实扩展已在 Edge 155 实载，Service Worker/选项页通过；真实站点音频 E2E 待验收。
- 不自动发布 1.0.0，等真实音频 E2E 通过。

## 4.3 视频音频校准（实验）

- 「检测音频」：尝试 `video.captureStream()`，报告是否有可用音轨。
- 「音频校准 8s」：播放视频 8 秒，采样 RMS，与 cue 活动做相关性。
- 搜索 ±15 秒；静音/相关性不足会拒绝。
- 跨域、DRM、无音轨媒体通常会提示“不可分析”，请手动校准。
- 不会接管或静音原视频音频。
- 结果只作为建议，必须确认后应用。

## 5. 字幕外观

- 字号、字重 400–800。
- 文字颜色、描边颜色、描边宽度（0–6px，0.5px 步进）。
- 背景颜色、背景不透明度。
- 纵向位置 60%–96%，拖动时实时移动。
- 投影阴影：启用、颜色、不透明度、模糊、X/Y 偏移。
- 平滑描边：24/32 向 text-shadow。
- 自带 WebVTT `line` 的 cue 优先保留作者位置。

设置保存在 `chrome.storage.local` 的 `smartSubtitle.settings.v1`。
选项页支持保存、恢复默认、清除本地数据。

## 6. ASS/SSA 字幕

- 支持 `.ass` / `.ssa`。
- 解析 `[Script Info]`、`[V4 Styles]`、`[V4+ Styles]`、`[Events]`。
- 支持常用标签：`\an`、`\pos`、`\fs`、`\b`、`\i`、颜色、`\bord`、`\shad`、`\r`。
s`、``、`\i`、颜色、`ord`、`\shad`、`
`。
- 覆盖层跟随视频位置和尺寸；按 `currentTime - offset` 显示。
- 支持 9 宫格对齐、`\pos`、多行、描边、阴影。
- 支持偏移、启用/禁用、移除、字幕库、在线下载。
- ASS 使用文件内样式；外观面板的字体/描边/位置不覆盖 ASS。
- 不支持：`\move`、`\t`、卡拉 OK、矢量绘图、复杂旋转/裁剪。

## 7. 多视频与动态页面

- 自动扫描 HTML5 `<video>`。
- 多视频下拉切换。
- SPA 动态添加/删除视频会自动更新。
- 视频销毁/切换时清理旧轨道并恢复网页原生 TextTrack。
- 仅顶层文档；iframe 内视频不支持。

## 8. 本地字幕匹配

1. 面板「字幕匹配」自动预填片名、年份、语言。
2. 可手动修改；「用识别结果」恢复。
3. 「选择候选字幕…」一次选多个本地 SRT/VTT/ASS。
4. 按片名 0.50、年份 0.18、时长 0.20、语言 0.07、集数 0.05 评分。
5. 显示分数、置信度、理由、冲突项。
6. 点击「使用此字幕」加载。
7. 完全离线，不上传。

低置信度/缺时长会降低 coverage，不会标成满分。

## 9. 字幕库缓存

- 手动加载或应用候选后自动缓存。
- 「加载字幕库」把最近字幕作为候选参与评分。
- 最多 50 条，最近使用优先。
- 缓存保存在扩展源 IndexedDB，不写宿主网页 origin。
- 清除本地数据会删除缓存。

## 10. OpenSubtitles 在线搜索

### 准备

1. 在 [OpenSubtitles](https://www.opensubtitles.com/) 获取 API Key。
2. 设置页「在线字幕来源」填写 Key。
3. 勾选「启用在线搜索」并保存。
4. 允许 `https://*.opensubtitles.com/*` 权限。

安装时**不请求**该域名权限；只有显式启用才请求。

### 测试与搜索

1. 点「测试连接」；成功会显示返回条数，失败显示具体原因。
2. 面板「字幕匹配」→「在线搜索」。
3. 只发送片名、年份、语言、季/集；不发送视频、音频、字幕文件。
4. 结果与本地候选一起评分。
5. 点击「使用此字幕」才下载正文。
6. 下载成功后进入字幕库。

API Key 不进入 content script；网络请求由 Service Worker 完成。

### 常见错误

| 错误 | 处理 |
|---|---|
| 在线来源模块未加载 | 更新到 0.9.11，重新加载扩展并刷新网页 |
| 未授予 OpenSubtitles 域名权限 | 重新勾选启用，保存并允许权限 |
| AUTH_ERROR / 401/403 | Key 无效、过期或账号/API 受限 |
| NETWORK_ERROR | 网络、代理或浏览器拦截 |
| ZIP_UNSUPPORTED | OpenSubtitles 返回 ZIP；当前不会自动解压 |
| 连接成功但 0 条 | 手动修正片名/年份；演示页标题不是影片名时搜不到 |

## 11. 权限与隐私

- 安装权限：`activeTab`、`scripting`、`storage`。
- 无安装时 `host_permissions`。
- 可选权限：`https://*.opensubtitles.com/*`。
- 不访问摄像头、麦克风；标签页音频仅在用户点击「标签页音频 8s」时通过 tabCapture 捕获并本地分析。
- 不上传字幕、视频、音频、设置。
- 在线启用后只发送片名/年份/语言/季集。
- 清除本地数据删除设置、字幕缓存、API Key，并移除可选域名权限。

## 12. 已知限制

- ASS/SSA 是子集渲染：不支持 `\move`、`\t`、卡拉 OK、矢量绘图、复杂旋转/裁剪。
- 自动偏移是首尾双锚点启发式；音频校准是实验功能，跨域/DRM 可能不可用；分段对齐未实现。
- iframe、Shadow DOM 内视频、Canvas/DRM 播放器不支持。
- 原生 `<video>` 全屏时面板可能被排除在全屏层外。
- 真实 OpenSubtitles 扩展内网络/权限链路需在安装版中验收。
- OpenSubtitles 下载配额由用户账号决定；ZIP 不自动解压。
- 站点覆盖有限；未做完整站点矩阵。
- Android 未实现。
