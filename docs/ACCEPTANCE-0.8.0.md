# v0.8.0 自动时间轴安全分析 2.0 验收报告

- 日期：2026-10-18
- 版本：`0.8.0`
- 触发场景：
  - 视频 1:28:42（5322s）
  - 字幕 1170 条，末条 1:28:13（5293s）
  - 实际偏移 0 时字幕正确
  - 旧版自动建议 +28775ms
- 结论：**安全分析通过；仍不是音频/语音自动对齐**

## 1. 根因

旧版只看尾差：

```text
5322s - 5293s = 29s
```

但末尾 29 秒通常是片尾/演职员表，不是字幕整体延迟。
旧版把这个差值作为 +28775ms 建议，并显示应用按钮。

## 2. 修复

- 首条锚点：`-firstStartMs`。
- 末条锚点：`videoDuration - lastEndMs`。
- 两者方向冲突超过 15 秒：拒绝（`ANCHOR_CONFLICT`）。
- 尾差超过 **10 秒**：拒绝（`TAIL_TOO_FAR`）。
- 当前场景：
  - 首条接近 0；
  - 末条差 29 秒；
  - 两个锚点不一致 → 不给建议，不显示应用按钮。
- 手动归零、±500、数字输入保持可用。

## 3. 测试

```text
tests 106
pass 106
fail 0
duration_ms 522.1542
```

新增：

- 29 秒尾差场景拒绝；
- 首尾锚点冲突拒绝；
- 20 秒尾差拒绝；
- 原有 +2000ms 小尾差仍通过。

## 4. 当前能力边界

自动分析只能在小尾差、首尾锚点一致时给建议：

- 不访问音频，不做语音识别；
- 首条/末条都受片头/片尾影响；
- 尾差 >10 秒不自动建议；
- 真正的音画对齐、分段漂移仍未实现。

## 5. 用户操作

1. 更新到 v0.8.0。
2. 重新加载扩展、刷新页面。
3. 当前截图场景点「分析时间轴」会提示尾差过大，不再出现 +28775ms。
4. 字幕 0 偏移正确时点「归零」即可。
