# 使用说明

本文档对应 Smart Subtitle `0.9.11`。扩展适用于桌面 Chrome / Edge（Manifest V3），仅处理网页中的 HTML5 `<video>`。

## 安装

1. 下载或克隆仓库。
2. 打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `manifest.json` 所在目录。
4. 打开网页并播放视频，点击扩展图标，或按 `Alt + Shift + S`。

首次点击通过 `activeTab` 授予当前页权限；刷新页面后需要重新点击。iframe 内视频暂不支持。

## 设置页

可通过以下入口打开：

- 面板右上角齿轮；
- 面板「字幕外观」底部的「更多设置」；
- `chrome://extensions/` → 扩展详情 → 扩展程序选项；
- 右键工具栏扩展图标 →「选项」。

设置保存在 `chrome.storage.local`，支持恢复默认和清除本地数据。

## 加载字幕

1. 选择目标视频。
2. 点击「选择 SRT / VTT / ASS 字幕」。
3. 支持 UTF-8、UTF-16LE/BE，无法识别时回退 GB18030。
4. 加载后显示文件名、格式、条数和结尾时间。
5. 可重新加载或移除字幕。

单文件上限 8 MB。ASS/SSA 使用独立覆盖层，不使用原生 `<track>`。

## 时间偏移

- 快捷按钮：`−500`、`−100`、`−50`、`+50`、`+100`、`+500 ms`。
- 也可输入数值后点击「应用」。
- 正数表示字幕延后，负数表示提前。
- 支持撤销和归零。
- 范围：`−3,600,000` 到 `+3,600,000 ms`。
- 偏移后完全落在视频开始前的 cue 会被移除。

## 自动时间轴

### 首尾锚点分析

- 位置：「时间偏移」→「分析时间轴」。
- 同时检查首条和末条字幕的偏移方向。
- 显示置信度与警告；最高为中置信度。
- 只有点击「应用建议」才会修改偏移，可撤销。
- 尾差超过 10 秒或首尾锚点冲突时拒绝。
- 依赖视频时长；片尾、彩蛋、缺失结尾会影响判断。

### 首句对齐（推荐）

用首条字幕作为锚点，不需要理解台词内容：

1. 将视频回到片头，保持播放。
2. 点击「自动检测首句 30s」。
3. 扩展捕获标签页前 30 秒音频，检测第一段持续声音。
4. 用检测到的声音起点和首条字幕起点计算偏移。
5. 确认后点击「应用建议」。

片头若有音乐/音效，自动检测可能把音乐当首句；此时改用手动：

1. 播放到首句台词开始。
2. 点击「手动标记首句」。
3. 用毫秒按钮修正约 0.2–0.5 秒的点击反应延迟。

自动检测需要 `tabCapture` 权限；手动标记不需要音频。

### 台词锚点（推荐）

音频相关性不稳定时，使用台词文本作为锚点：

1. 播放到你要对齐的台词，暂停。
2. 在「台词锚点」输入台词中的几个字（至少 2 个字符）。
3. 点击「查找」，从结果中选择正确的一句。
4. 确认「当前时间 → 建议偏移」。
5. 点击「以当前时间对齐」。

计算方式：

```text
offset = 当前视频时间 - 选中字幕的开始时间
```

正数表示字幕延后，负数表示提前。该方式不读取音频，适用于跨域、DRM 或音频无法采集的页面，但仍需要用户确认台词和当前时间。

### 音频校准（实验）

- **视频音频**：尝试 `video.captureStream()`；跨域/DRM 媒体可能无音轨。
- **标签页音频**：通过 `tabCapture` + `offscreen` 捕获当前标签页声音，连续采样约 40 秒。
- 采样后拆成多个窗口，比较音频活动与字幕活动；一致性不足会拒绝。
- 诊断面板显示逐窗口偏移、分数、第二独立峰、活动比例、MAD、候选共识等信息。
- 音频校准不保证所有站点可用，所有建议都必须手动确认。

## 字幕外观

- 字号、字重 400–800。
- 文字颜色、描边颜色、描边宽度 0–6 px。
- 背景颜色和不透明度。
- 纵向位置 60%–96%，拖动时字幕实时移动。
- 投影阴影：颜色、不透明度、模糊、X/Y 偏移。
- 平滑描边使用 24/32 向 `text-shadow`。
- 自带 WebVTT `line` 的 cue 优先保留作者位置。

以上面板设置不覆盖 ASS/SSA 文件内样式。

## ASS/SSA

- 支持 `.ass`、`.ssa`。
- 解析 `[Script Info]`、`[V4 Styles]`、`[V4+ Styles]`、`[Events]`。
- 支持常用标签：`\an`、`\pos`、`\fs`、`\b`、`\i`、颜色、`\bord`、`\shad`、`\r`。
- 覆盖层跟随视频位置和尺寸，按 `currentTime - offset` 显示。
- 支持 9 宫格、`\pos`、多行、描边和阴影。
- 播放器容器全屏时覆盖层会移入全屏容器；直接 `<video>` 元素全屏可能无法显示。
- 不支持：`\move`、`\t`、卡拉 OK、矢量绘图、复杂旋转/裁剪。

## 多视频与动态页面

- 自动扫描 HTML5 `<video>`。
- 多视频可通过下拉框切换。
- SPA 动态添加或删除视频时自动更新。
- 视频销毁或切换时清理旧轨道并恢复网页原生 TextTrack。

## 本地字幕匹配

1. 面板「字幕匹配」会自动填写片名、年份、语言。
2. 可手动修改，或点击「用识别结果」恢复。
3. 一次选择多个本地字幕作为候选。
4. 按片名、年份、时长、语言、集数评分。
5. 显示分数、置信度、理由和冲突项。
6. 点击「使用此字幕」加载。

匹配与解析完全离线。

## 字幕库

- 手动加载或应用候选后自动缓存。
- 「加载字幕库」会把最近字幕加入候选评分。
- 最多 50 条，最近使用优先。
- 缓存保存在扩展源 IndexedDB，不写入网页 origin。
- 清除本地数据会删除缓存。

## OpenSubtitles 在线搜索

1. 在 OpenSubtitles 获取 API Key。
2. 设置页填写 Key。
3. 勾选「启用在线搜索」并保存。
4. 允许 `https://*.opensubtitles.com/*` 权限。

搜索只发送片名、年份、语言、季/集；不发送视频、音频或字幕文件。点击「使用此字幕」后才下载正文。API Key 不进入 content script，网络请求由 Service Worker 完成。

常见错误：

| 错误 | 处理 |
|---|---|
| 在线来源模块未加载 | 重新加载扩展并刷新页面 |
| 未授予域名权限 | 重新勾选启用并允许权限 |
| `AUTH_ERROR` / 401 / 403 | 检查 Key、账号或 API 配额 |
| `NETWORK_ERROR` | 检查网络、代理或浏览器拦截 |
| `ZIP_UNSUPPORTED` | OpenSubtitles 返回 ZIP，当前不自动解压 |
| 连接成功但 0 条 | 修正片名/年份；演示页标题不是影片名 |

## 权限与隐私

- 必需权限：`activeTab`、`scripting`、`storage`。
- 音频校准权限：`tabCapture`、`offscreen`，仅在用户主动点击时使用。
- 可选域名权限：`https://*.opensubtitles.com/*`，显式启用时才请求。
- 不访问摄像头、麦克风。
- 不上传字幕、视频、音频或设置。
- 标签页音频只在本地采样，采样结束即停止。

## 已知限制

- ASS/SSA 仅覆盖常用子集，不是完整 libass。
- 自动时间轴是实验能力，不保证所有站点/片源可用。
- iframe、Shadow DOM 内视频、Canvas/DRM 播放器不支持。
- 原生全屏时面板可能不在全屏层内。
- 站点覆盖范围有限，未做完整站点矩阵。
- Chrome Android 不支持扩展；Firefox Android 使用独立构建（手动首句/文本锚点）。

## Firefox Android

Firefox Android 版使用 `dist/firefox/` 构建：

- 支持文本锚点、手动首句、字幕外观、偏移；
- 不读取标签页音频，自动首句/音频按钮隐藏；
- 通过 AMO 签名后安装。

构建：

```bash
npm run build:firefox
```
