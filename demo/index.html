PHASE 2B · LOCAL FIRST

本地字幕助手

在网页 HTML5 视频上加载本地 SRT / VTT 字幕，调节整体时间偏移和字幕外观。 字幕和音频不会离开这台电脑。

Chrome MV3 无上传 SRT / VTT 整体偏移 实时外观 投影阴影 本地候选匹配
▶
选择一段本地视频 演示页不附带视频文件

尚未选择视频。可以使用任何你有权使用的本地 MP4/WebM。

01

打开扩展面板

点击工具栏里的「本地字幕助手」图标，或按 Alt + Shift + S。

02

选择字幕

在面板中点击「选择 SRT / VTT 字幕」，选择本目录下的 sample.zh.srt，或使用你自己的字幕。

03

校准与外观

用毫秒按钮微调并「归零」；在「字幕外观」中调整字号、字重、描边、阴影和纵向位置，拖动位置时字幕实时移动。

示例字幕

两个示例都从视频开头附近开始，方便验证加载、显示和偏移。

当前阶段只检测顶层文档中的 HTML5 <video>。 iframe、Shadow DOM、Canvas 和 DRM 播放器不在支持范围内。 如果页面使用视频元素全屏，浏览器会把面板排除在全屏层之外；字幕本身仍会显示。
